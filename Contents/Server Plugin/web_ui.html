    ESPHome boards announcing themselves on this network. Boards already in Indigo are marked.

    Wi-Fi & secrets

    Stored in Device Builder's secrets file and built into firmware. Values can be set but never shown again. Boards pick up a change the next time they're installed, so update boards before changing your router.

    Other secrets

    Use it in YAML as !secret name.

    New board

    Device Builder writes a starter configuration with Wi-Fi, OTA updates and an encrypted API key, ready for Indigo.
